# Dealflow

Use this reference for reading or changing the investment pipeline.

## Read the board

Open `Dealflow`. The columns are `Novo`, `Conversando`, `Analisando`, `Comite`,
`Investido`, and `Arquivado`. A card can show company, sector, funding round, and
next step.

To read founders, internal owner, or notes, open the card. It opens `Editar Deal`;
read without changing fields and close with `Cancelar`.

## Create or edit a deal

Use `Novo Deal` or the add control in a stage. To edit, open the card or use
`Ações de {company}` → `Editar`.

Fields: `Empresa`, `Setor`, `Rodada`, `Fundadores`, `Estagio`, `Responsavel
Interno`, `Próximo Passo`, and `Notas`. Round choices are `Pre-Seed`, `Seed`,
`Series A`, `Series B`, and `Series C+`. Company names are not unique; compare
stage, sector, round, owner, and next step before acting.

## Move or delete a deal

Use `Ações de {company}` → `Mover para...` and select the destination. Selecting
the destination writes immediately, so preview company, current stage, and target
stage before opening that menu. Prefer this named action over drag-and-drop.

Use `Ações de {company}` → `Excluir` only after a deletion preview and explicit
confirmation. Verify removal from the column afterward.

The platform has no automatic deal-to-startup conversion, activity history,
search, filters, or bulk import. Never imply that moving a deal to `Investido`
creates a startup record.
